# FIT4014 A3 – Portfolio Nguyễn Trung Kiên

## 1. Giới thiệu
Website portfolio cá nhân dạng website tĩnh, xây dựng bằng HTML5, CSS3 và JavaScript nhỏ cho menu, thanh tiến độ cuộn và hiệu ứng xuất hiện khi cuộn trang.

## 2. Cấu trúc thư mục
```text
fit4014_a3_portfolio/
├── index.html
├── style.css
├── README.md
├── AI_LOG.md
├── BAO_CAO_A3.md
└── assets/
    └── hero-workspace.png
```

## 3. Chạy thử
Giữ nguyên cấu trúc thư mục, mở `index.html` bằng trình duyệt hoặc dùng Live Server trong Visual Studio Code. Không di chuyển riêng `index.html` khỏi thư mục `assets`.

## 4. Triển khai GitHub Pages
1. Tạo repository GitHub và tải toàn bộ nội dung thư mục lên repository.
2. Chọn **Settings → Pages**.
3. Chọn **Deploy from a branch**, branch `main`, folder `/(root)`, rồi Save.
4. Chờ GitHub Pages hoàn tất triển khai.
5. Mở URL được GitHub cung cấp; thử lại các liên kết và đối chiếu nội dung với repository.

Tài liệu tham khảo: https://docs.github.com/en/pages

## 5. Nội dung cần cá nhân hóa trước khi nộp
- Thay mô tả dự án mẫu bằng sản phẩm thật và bổ sung liên kết tương ứng.
- Bổ sung URL GitHub Pages thực tế.
- Chạy toàn bộ kiểm thử trong `BAO_CAO_A3.md`, ghi kết quả thực tế và thêm ảnh minh chứng.
- Hoàn thiện AI_LOG theo đúng những lần đã sử dụng AI.
- Quay video demo sản phẩm và chuẩn bị phần phản biện theo yêu cầu giảng viên/LMS.

**Lưu ý:** Trạng thái “Chưa kiểm tra/Chưa triển khai” được giữ nguyên có chủ đích. Không chuyển thành “Đạt” nếu chưa thực hiện kiểm tra thực tế.
